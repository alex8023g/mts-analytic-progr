# запуск

1. убедиться, что PostgreSQL запущен
2. в папке backend создать .env файл на основании .env.example и указать в нём DATABASE_URL
3. в папке frontend создать файл .env: `NEXT_PUBLIC_API_URL=http://127.0.0.1:8000`
   далее все команды выполняются из корневой папки
4. установить зависимости: `npm run install:all`
5. создать базу данных и таблицы: `npm run db:create`
6. запустить backend: `npm run backend:prod`
7. собрать fronted: `npm run frontend:build`
8. запустить frontend: `npm run frontend:prod`

# обработка повторяющихся и неоднозначных записей

4е Семенова это один человек или 3 или 4 разных человека?
то ли при увольнении добавляется новая запись, то ли при переходе на другую должность добавляется новая запись, то ли при повторном приеме обновляется существующая запись?

явно не хватает даты рождения сотрудника для определения его уникальности

видна закономерность: некоторые уволенные сотрудники имеют запись со статусом Работает в том же отделе с той же датой приема на работу

принимаем утверждение, что записи с одинаковыми фио и одинаковым отделом и одинаковой датой приема на работу - это запись одного и того же человека и оставляем только запись в которой есть дата увольнения

также есть записи с приемом на работу в ту же дату с тем же фио, но в другом отделе;

т.к. нет достаточно данных (нет даты рождения сотрудника) и негде уточнить логику (возможно сотрудника перевели в другой отдел, но т.к. нет даты перевода, то невозможно определить какой из отделов актуальный а какой нет) также маловероятно что это полные тезки, которых приняли на работу в один и тот же день в разные отделы, поэтому принимаем что это запись одного и того же человека и оставляем только запись в которой есть дата увольнения

актуальность данных на выбранную дату определяется следующим образом: если дата приема сотрудника больше то этот сотрудник еще не принят на работу и он не отображается, если дата увольнения больше выбранной даты а дата приема на работу меньше, то сотрудник отображается со статусом Работает, если дата приема на работу и дата увольнения меньше выбранной даты, то сотрудник отображается со статусов Уволен.
